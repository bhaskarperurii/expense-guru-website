## GitHub Pages

1. Create a public repository, for example `expense-guru`.
2. Upload all files inside `expense-guru-website` to the repository root.
3. Go to Settings > Pages.
4. Source: Deploy from a branch.
5. Branch: main, folder: /root.
6. Your site URL will be: https://YOUR_USERNAME.github.io/expense-guru/
